## 隐私和发布检查

源码和两个 ZIP 解压后执行文件白名单和本地敏感模式扫描；不包含真实 profile、凭据、聊天、日志、备份、应用副本或 Git 历史。macOS ZIP 不含测试驱动。截图沿用虚构内容的演示图，不是 rc.5 新性能测量。扫描结果仅包含状态、文件数量和类别，不包含疑似秘密原文。

更新来源保持 enabled=false、repository=null、autoCheck=false：不自动联网、不注册后台定时检查。卸载保留未结束的侧聊，只有明确结束侧聊才删除对应会话和缓存。测试清理仅停止自己创建的服务和浏览器进程。

GitHub 上传前检查源码提交和实际附件；通过 GitHub 返回的 SHA-256 digest 核对上传内容，不额外下载 Release 附件，避免本次校验增加附件下载计数。

## 未验证与保留限制

- NOT RUN：在用户日常 Electron 桌面安装、真实 Finder 双击、真实模型回答与图片/文件读取。
- NOT RUN：Windows、Linux、rc.4、0.2.2 alpha 和其他 Harness 版本。
- 未新增长期 RSS 测量；既有 DOM/listener 增长和偶发窗口拖动问题未完全归因。
- 模式扫描降低发布隐私风险，不能证明所有潜在敏感信息绝对不存在。

本次不修改用户当前桌面插件、不自动退出应用，不修改应用包或全局 npm 依赖。旧 Release 保留，安装失败自动恢复；回退保留其他插件之后的独立配置更改。
