# 1.1.2 双击安装版：验收与隐私报告

日期：2026-10-26。目标：macOS、DeepSeek Harness 0.2.1-rc.3。

## 本版改动

主要安装入口改为完整解压 macOS ZIP 后双击「安装或更新.command」。提供检查安装、回退、卸载与选用的手动检查更新入口。优先应用内置运行环境，缺失时只检查现有 Node 20+，不安装其他软件。

新增原生组合包、非受管依赖、普通模块目录与外部链接冲突拒绝；安装、检查、回退、卸载都不会接管原生安装。原生用户需自行在 Harness 停用并卸载原生包，退出应用后再安装。旧脚本版可直接升级。

脚本载荷不再声明 dsh.bundle，避免在原生管理器中被重复启用。业务运行代码 index.js / host.js / client.js / update.js 与 1.1.1 相同；版本和发行元信息更新为 1.1.2。ZIP 校验白名单增加明确的 README.en.md，继续拒绝未知根文件和危险路径。

## 退出、恢复与边界

安装失败自动恢复安装前的受管对象；回退保留其他插件后续独立配置改动。如果本插件被手工更改，则拒绝盲目覆盖。不会自动关闭用户应用，不修改全局 npm 依赖或应用包。

成功时脚本进程自动结束；交互终端错误最多等 20 秒，用户可按回车提前结束。Terminal 窗口本身是否自动关闭取决于用户终端偏好，本脚本不修改全局设置。测试进程按本次创建的进程组停止并等待退出，不按应用名清理。

更新来源为 enabled=false、repository=null、autoCheck=false，不做自动网络检查、不注册后台定时任务。手动检查未配置时零请求；未来启用更新仍需显式确认与兼容校验。侧聊内原生协议更新入口也保持关闭，不混用 ZIP 与 .tgz 清单。

## 隐私检查

最终源码 ZIP 和最终 macOS ZIP 解压后执行文件白名单、敏感模式与个人路径扫描。macOS ZIP 只含运行载荷、四个运行工具、必要第三方库及说明；不包含开发测试、报告日志、真实配置、凭据、备份或应用运行时副本。演示截图使用虚构数据。

机器可读结果和 SHA-256 校验文件随包提供，报告不展示敏感原文。模式扫描不能证明所有可能的敏感信息都绝对不存在。
