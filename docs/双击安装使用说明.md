# macOS 双击安装与回退（1.1.3）

仅支持 DeepSeek Harness 0.2.1-rc.5。新用户和旧脚本版用户都下载 macOS ZIP，完整解压，自行退出 Harness 后，双击「安装或更新.command」。成功后重新打开 Harness，即可在主对话输入 /side。

安装器不会强制结束应用、安装额外运行时、修改应用包或全局 npm 依赖。使用应用自带的 Node 环境，失败时检查系统 Node 20+。检查未通过则停止。

若已有原生 .tgz 安装，请先在 Harness 停用并卸载侧聊，然后退出应用再运行脚本。原生卸载保留未结束侧聊数据。没有原生包就不需要运行迁移工具。

- 检查安装.command：只核对，不改变配置，应用运行时也可检查。
- 回退上一版.command：退出应用后执行，恢复最近一次操作前的受管状态。初次安装的回退会回到未安装；升级的回退会恢复旧脚本版；卸载的回退会恢复安装。
- 卸载.command：退出应用后执行，仅删除侧聊安装文件和受管配置，保留会话与备份。
- 检查更新.command：选用入口；发布源未配置时不联网。当前安装工具的自动网络检查默认关闭，没有后台定时任务。

只备份或恢复本插件拥有的安装对象，回退保留其他插件后续独立配置改动。若本插件被手动修改或发现冲突，回退会拒绝覆盖。

备份位于本机 profile 的 .side-chat-installer。请保留安装包文件夹，不要上传备份或整个 profile。安装完成不代表备份被删除。

成功时脚本自动退出；错误时保留明确提示，在交互终端最多等待 20 秒。终端窗口是否随进程结束关闭取决于用户的 Terminal 设置；脚本不会修改全局终端偏好。

macOS 版本、运行环境或 profile 不符合条件时，请保留提示并反馈。不要自行删除其他插件或整个配置目录。

版本回退也需要匹配 Harness：1.1.3 对应 rc.5，旧 1.1.2 对应 rc.3。恢复旧文件不代表它已兼容新版客户端；不要绕过版本校验。
