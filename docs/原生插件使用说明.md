# 侧边聊天 1.1.1 原生插件版

仅验证 macOS、DeepSeek Harness 0.2.1-rc.3。署名 HHH84h，MIT。

## 首次安装

下载 dsh-client-ui-side-1.1.1.tgz，保留原后缀，无需解压。打开 Harness 左侧「插件」，选择「添加插件」，输入这个文件的完整路径，安装并启用，按应用提示自行重启。无需额外安装 Node 或发布到 npm。安装器可能访问包源，属 Harness 自身行为。

## 已安装旧脚本版

先解压随附迁移 ZIP。自行完全退出 Harness，双击「迁移旧版.command」，成功后再启动 Harness 并导入 .tgz。不要让两种安装方式同时生效。工具优先使用应用自带运行环境，不会强制关闭应用。

迁移只移除本插件旧条目和旧链接；会话、状态和其他插件配置保留。备份在本机 profile 的 .side-chat-installer 中，包含个人配置，切勿上传。无需迁移的新用户不要运行恢复。

恢复旧版：先在 Harness 停用并卸载原生插件，再退出应用，双击「恢复旧版.command」。发现本插件配置被改动时会停止恢复；其他插件独立改动会保留。

原生插件版本之间回退：停用并卸载当前原生包，再导入你保留的旧 .tgz。迁移工具的「恢复旧版」仅用于恢复之前的脚本安装方式。

## 使用与停用

/side 或 /side 问题打开侧聊。侧聊只读，首问捕获主聊快照；点击「刷新上下文」更新。收起保留，明确结束侧聊才删除。停用和卸载插件会释放运行资源，但不会删除未结束侧聊的历史和恢复状态。

## 插件更新

侧聊工具栏的「检查更新」为手动查询；此版本发布源未配置，显示未启用，不会联网。以后配置公开发布源后会显示兼容版本、下载链接与 SHA-256；下载后在 Harness 插件管理器安装。若提示已安装，先停用并卸载旧插件，再导入新包，按提示重启。不会后台更新，也不会自动替换正在运行的插件。

客户端更新通常保留用户插件；不兼容时 Harness 可能跳过加载。此时插件内检查按钮不可用，应到今后正式发布页面下载适配版，不建议绕过版本检查。当前尚无发布页面，不要相信第三方代发链接。

## 隐私和限制

无项目自有遥测或自动上传。模型请求仍会将问题、主聊快照和读取的内容发送给你配置的模型服务；临时侧聊不等于离线处理或磁盘安全擦除。诊断导出先展示信息类别。

Windows/Linux、其他 Harness 版本未验证。既有页面资源累计增长和顶部拖动偶发问题尚未完全归因，不宣称本版解决。测试使用 fake provider，不代表真实模型回答已测试。
