# 双击安装版的更新入口

主要更新方式：下载适配的新版 macOS ZIP，退出 Harness 后运行新版「安装或更新.command」。它会先备份，再更新插件，失败自动恢复。

随附「检查更新.command」使用 side-chat-update.json 的 ZIP 安装器协议；当前 update-source.json 为 enabled=false、repository=null、autoCheck=false，手动和启动检查均不会发起更新请求。没有后台定时器或常驻更新进程。

侧聊顶部保留原来的手动检查入口；plugin/update-source.json 同样关闭。它的原生包协议与 ZIP 协议不同，本版不会启用该原生发布源或自动引导混装。维护者若要未来统一入口，应单独适配并验证，不能混用清单。

双击工具只在来源已配置、发现兼容更新且用户明确确认时下载校验后的 ZIP，并要求退出 Harness 后安装。默认发行包没有在线更新源，不承诺当前可在线更新。
